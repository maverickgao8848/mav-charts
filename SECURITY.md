# Security Policy

## Supported versions

Security fixes are provided for the latest published MAV Charts release. During the `0.x` prerelease period, consumers should update to the newest patch before reporting a reproducibility issue.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository. If that feature is unavailable, contact the maintainer through the email listed on the active GitHub account profile and include:

- affected package and version;
- a minimal reproduction or proof of concept;
- expected impact;
- any known mitigations.

We aim to acknowledge a report within five business days and will coordinate disclosure after a fix is available. Please avoid accessing data that is not yours or disrupting services while investigating.
